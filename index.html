🏈 NFL Tracker

Jogos e placares: ESPN. Vídeos: canal oficial da NFL no YouTube. Suas marcações ficam salvas neste navegador e, com a sincronização ativada (⚙), em todos os seus aparelhos.

Configurações

Para o link abrir direto o vídeo de cada jogo, cole uma chave da YouTube Data API v3. Ela fica só neste navegador e o app gasta poucas unidades da cota diária.

  1. Acesse console.cloud.google.com e crie um projeto.
  2. Ative a "YouTube Data API v3".
  3. Em Credenciais, crie uma chave de API e restrinja-a a https://victor-orrico.github.io/*

Sincronizar entre aparelhos

No primeiro aparelho: em github.com/settings/tokens crie um token clássico só com a permissão "gist", cole abaixo e toque em Ativar.
